# FederalStore — магазин скинов и гайдов для CS2

Магазин цифровых товаров для игроков Counter-Strike 2: скины, кейсы, аксессуары и гайды.

## Возможности

- Каталог с товарами и ценами
- Личный кабинет с историей заказов
- Оплата: СБП, карта, криптовалюта, PayPal
- Уведомления о заказах в Telegram
- Отзывы покупателей
- Тёмная тема и современный дизайн

## Технологии

- Next.js 14 (App Router)
- Supabase (auth, база данных, storage)
- Vercel (хостинг и деплой)

## Запуск

```bash
npm install
npm run dev
```

Для работы нужны переменные окружения (см. `.env.example`).
